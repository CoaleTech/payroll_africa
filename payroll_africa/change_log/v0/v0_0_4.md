# Payroll Africa 0.0.4

Country setup now follows Payroll Africa Settings, Kenya PAYE is computed after the statutory deductions, plus complete documentation and a demo video.

## New
- Ticking or unticking a country in Payroll Africa Settings creates or removes that country's Salary Structure, Salary Components and Income Tax Slab.
- Install and `bench migrate` enable the country of every Company automatically. If every country is ticked (the untouched default), only the Company countries are kept.
- Automatic country detection: Payroll Africa now enables the country of each Company automatically — on install and whenever a new Company is created. Additive only; it never turns off a country you have disabled.
- Comprehensive user documentation with screenshots, plus a single-file HTML and PDF manual.
- A UI demo video walking through the full payroll workflow, from enabling a country to a Salary Slip with statutory deductions and a statutory report.

## Improved
- `bench migrate` only provisions enabled countries. Previously all 54 countries' structures, components and slabs were recreated on every migrate.
- Components shared between countries (e.g. "PAYE") are kept while any enabled country uses them.
- Records already used by Salary Structure Assignments or Salary Slips are deactivated instead of deleted.
- Uninstall cleanup now covers all 54 countries (previously 21) and no longer force-deletes linked records.
- README now uses the green Africa app icon instead of the line-art sketch.
- Publisher, author, and source copyright aligned to CoaleTech (support@coale.tech).

## Fixed
- Kenya PAYE was calculated before NSSF, SHIF and Housing Levy were on the slip, so it taxed pre-deduction pay. It is now re-run after them.
- Kenya personal relief (KES 2,400) is now subtracted from PAYE as a tax credit, never below zero.

## Removed
- The Salary Structure component filter (`payroll_africa_salary_structure.js`, `get_filtered_salary_components`, `VALID_SUFFIXES`). Disabled countries' components no longer exist, so it is not needed.

## Technical
- GitHub Actions CI (server tests on Frappe v16) and pre-commit linters.
- Country-name aliases (Cape Verde, Swaziland) handled during auto-detection.
- 347 unit tests passing.
